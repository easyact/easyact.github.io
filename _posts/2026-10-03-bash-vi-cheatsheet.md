# 🐚 Bash + Vi/Vim 快捷键 Cheat Sheet

## 📌 Bash 快捷键

### ⌨️ 删除操作（最常用）
| 操作 | 快捷键 |
|------|--------|
| **删除前一个词** | `Ctrl + W` |
| 删除前一个字符 | `Ctrl + H` 或 `Backspace` |
| 删除后一个字符 | `Ctrl + D` |
| 删除光标到行首 | `Ctrl + U` |
| 删除光标到行尾 | `Ctrl + K` |
| 删除光标后到单词结尾 | `Alt + D` |
| 删除光标前到单词开头 | `Alt + Backspace` |

### 🖱️ 光标移动
| 操作 | 快捷键 |
|------|--------|
| 移动到行首 | `Ctrl + A` |
| 移动到行尾 | `Ctrl + E` |
| 左移一个字符 | `Ctrl + B` |
| 右移一个字符 | `Ctrl + F` |
| 左移一个单词 | `Alt + B` |
| 右移一个单词 | `Alt + F` |

### 📜 历史命令
| 操作 | 快捷键 |
|------|--------|
| 搜索历史命令 | `Ctrl + R` |
| 上一条命令 | `Ctrl + P` 或 `↑` |
| 下一条命令 | `Ctrl + N` 或 `↓` |
| 再次搜索 | `Ctrl + O` |

### ✂️ 剪切/粘贴
| 操作 | 快捷键 |
|------|--------|
| 剪切到行首 | `Ctrl + U` |
| 剪切到行尾 | `Ctrl + K` |
| 剪切前一个词 | `Ctrl + W` |
| 粘贴最后一次剪切的 | `Ctrl + Y` |

### 🖥️ 终端控制
| 操作 | 快捷键 |
|------|--------|
| 清屏 | `Ctrl + L` |
| 中断当前进程 | `Ctrl + C` |
| 停止当前进程 | `Ctrl + Z` |
| 暂停输出 | `Ctrl + S` |
| 恢复输出 | `Ctrl + Q` |

## 📌 Vi/Vim 常用命令

### 🔹 模式切换
| 操作 | 命令 |
|------|------|
| 从普通模式进入插入模式 | `i` (光标前插入) |
| 从普通模式进入插入模式 | `a` (光标后插入) |
| 从普通模式进入插入模式 | `o` (下一行插入) |
| 从普通模式进入插入模式 | `O` (上一行插入) |
| 从普通模式进入插入模式 | `I` (行首插入) |
| 从普通模式进入插入模式 | `A` (行尾插入) |
| 返回普通模式 | `Esc` |
| 进入命令模式 | `:` |

### 🔹 光标移动
| 操作 | 命令 |
|------|------|
| 左/下/上/右 | `h` / `j` / `k` / `l` |
| 移动到行首 | `0` 或 `^` |
| 移动到行尾 | `$` |
| 移动到文件开头 | `gg` |
| 移动到文件结尾 | `G` |
| 移动到第 n 行 | `:n` 或 `nG` |
| 向下移动半屏 | `Ctrl + D` |
| 向上移动半屏 | `Ctrl + U` |
| 移动到下一个单词开头 | `w` |
| 移动到上一个单词开头 | `b` |
| 移动到单词结尾 | `e` |

### 🔹 删除操作
| 操作 | 命令 |
|------|------|
| 删除光标所在字符 | `x` |
| 删除光标前一个字符 | `X` |
| 删除当前行 | `dd` |
| 删除 3 行 | `3dd` |
| 删除从光标到行尾 | `D` |
| 删除从光标到单词结尾 | `dw` |
| 删除从光标到行首 | `d0` |
| 删除到文件结尾 | `dG` |
| 删除括号内内容 | `di(` 或 `di{` 或 `di[` |

### 🔹 复制/粘贴/剪切
| 操作 | 命令 |
|------|------|
| 复制当前行 | `yy` |
| 复制 3 行 | `3yy` |
| 复制到单词结尾 | `yw` |
| 粘贴到光标后 | `p` |
| 粘贴到光标前 | `P` |
| 剪切当前行 | `dd` (配合 p 粘贴) |
| 剪切到单词结尾 | `dw` |

### 🔹 撤销/重做
| 操作 | 命令 |
|------|------|
| 撤销 | `u` |
| 重做 | `Ctrl + R` |

### 🔹 搜索与替换
| 操作 | 命令 |
|------|------|
| 向后搜索 | `/pattern` |
| 向前搜索 | `?pattern` |
| 下一个匹配 | `n` |
| 上一个匹配 | `N` |
| 替换当前行第一个 | `:s/old/new/` |
| 替换当前行所有 | `:s/old/new/g` |
| 替换整个文件 | `:%s/old/new/g` |
| 替换并确认 | `:%s/old/new/gc` |

### 🔹 保存与退出
| 操作 | 命令 |
|------|------|
| 保存 | `:w` |
| 退出 | `:q` |
| 保存并退出 | `:wq` 或 `ZZ` |
| 强制退出（不保存） | `:q!` |
| 强制保存 | `:w!` |
| 另存为 | `:w filename.txt` |

### 🔹 可视模式（选中）
| 操作 | 命令 |
|------|------|
| 进入字符可视模式 | `v` |
| 进入行可视模式 | `V` |
| 进入块可视模式 | `Ctrl + V` |
| 复制选中 | `y` |
| 删除选中 | `d` |

### 🔹 实用技巧
| 操作 | 命令 |
|------|------|
| 重复上一个命令 | `.` |
| 显示行号 | `:set number` |
| 关闭行号 | `:set nonumber` |
| 语法高亮 | `:syntax on` |
| 查看当前文件信息 | `Ctrl + G` |
| 跳转到配对括号 | `%` |

## 📌 快速参考卡片

### Bash 三件套
Ctrl + W → 删除前一个词

Ctrl + U → 删除整行

Ctrl + R → 搜索历史

### Vi 三件套
i → 进入插入模式

dd → 删除当前行

:wq → 保存并退出

### Vi 求生命令（当你卡住时）
Esc → 回到普通模式

:q! → 强制退出（不保存）

ZZ → 保存并退出
